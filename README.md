# 📺 IPTV Russia 1 Generator for Smart TV

> Десктопное приложение с графическим интерфейсом (**PyQt5**) и асинхронным движком (**aiohttp**), предназначенное для автоматического поиска, проверки работоспособности и экспорта живых IPTV-потоков телеканала «Россия 1» в плейлист `russia1_working.m3u` на USB-флешку для просмотра на Smart TV.

---

## 🚀 Основные возможности

* **Автоматическое сканирование:** Загрузка актуальных каталогов IPTV-потоков из проверенных открытых источников.
* **Умный гибкий поиск:** Фильтрация каналов по ключевым словам (`Россия 1`, `Russia 1`) без учета регистра.
* **Асинхронная проверка (Latency):** Быстрая проверка доступности каждого потока с измерением задержки в миллисекундах (`ms`).
* **Определение реальных USB-флешек:** Автоматическое сканирование и определение вставленных съемных накопителей на Windows с помощью системного API.
* **Готовый плейлист для ТВ:** Автоматическое создание и сохранение файла `russia1_working.m3u` в корень выбранной флешки.
* **Предпросмотр на ПК:** Возможность кликнуть по любому найденному потоку в списке для его быстрой проверки во внешнем плеере VLC.

---

## 🛠 Технологии

* **Python 3.14**
* **PyQt5** (Графический интерфейс)
* **Aiohttp** (Асинхронные сетевые запросы)
* **Windows API (ctypes)** (Для точного определения съемных USB-накопителей)
